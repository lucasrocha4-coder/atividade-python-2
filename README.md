
# Atividades de Programação em Python

## Sobre o projeto

Este repositório contém cinco exercícios práticos
desenvolvidos em Python como parte de uma atividade
de programação.

## Exercícios desenvolvidos

**Exercício 1:** Conversão de idade expressa em dias
para anos, meses e dias.

**Exercício 2:** Verificação se três valores formam
um triângulo e cálculo de sua área.

**Exercício 3:** Identificação do menor entre três
números inteiros.

**Exercício 4:** Função para verificar se um número
é primo, com teste dos números de 1 a 100.

**Exercício 5:** Função que inverte as letras de
cada palavra de uma frase.

## Linguagem utilizada

- Python 3

## Como executar

Abra o terminal na pasta do projeto e execute:

python exercicio1.py

Para executar os demais exercícios, altere o nome
do arquivo conforme desejado.

## Objetivo

Praticar lógica de programação, variáveis,
estruturas condicionais, funções, repetições,
operações matemáticas e manipulação de textos.
